# Simulador de Filas - Metodos Analiticos de Simulacao

Simulador de fila simples baseado em eventos, utilizando o Metodo Congruente Linear para geracao de numeros pseudoaleatorios.

## Requisitos

- Python 3.x

## Como rodar

### Simulador

```bash
python simulador_fila.py
```

Executa as duas simulacoes configuradas:

- **G/G/1/5** - 1 servidor, capacidade 5, chegadas [3,5], atendimento [4,5]
- **G/G/2/5** - 2 servidores, capacidade 5, chegadas [3,5], atendimento [4,5]

Ambas com 100.000 numeros aleatorios, fila inicialmente vazia e primeiro cliente chegando no tempo 3.0.
